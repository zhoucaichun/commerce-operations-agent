# Public reference catalogue

`public_reference_catalog.csv` is a small, manually reviewed set of public product facts used to make the ShopPilot 3C demonstration look like a realistic merchant catalogue. Each row retains its public manufacturer collection URL and the date it was checked.

It is not a scrape job, a live feed, a price promise, a stock feed, or a statement that Anker or Belkin are ShopPilot merchants. The runtime labels every row as `public_reference_catalog`; pricing and availability must be refreshed through an approved merchant connector before any production use.
