# ShopPilot Agent 评测文档索引

本目录把评测视为 ShopPilot Commerce Agent 的产品能力，而不是上线前一次性的打分活动。它只覆盖本仓库的合成数据、合成商家和受控工具；不包含真实商家、客户、订单、库存或生产日志。

## 从这里开始

1. [企业级 Agent 评测流程](企业级Agent评测流程.md)：从业务目标、数据、Grader、离线/在线实验到发布门禁的完整闭环。
2. [ShopPilot 3C 评测体系](ShopPilot_3C评测体系.md)：将上述流程映射到推荐、兼容性、政策、订单、工单、人工接管和未来多模态链路。
3. [近年论文与框架综述](近年论文与框架综述.md)：近年顶会/行业轨代表论文、可借鉴方法、常用工程框架及选型建议。

本目录补充的是“如何以可复现证据证明这些契约被满足”。任何评测结论必须注明代码提交、数据集版本、模型/Prompt/规则版本、运行配置和已知局限；不能把合成环境通过写成真实商家生产能力。

## 当前状态（2026-10）

- 已有：145 条 Dify 来源的历史题目、确定性单元/冒烟评测、模型 Live Eval 脚本、受控工具 Trace，以及合成商品/政策/订单数据。
- 未完成：统一 Case Schema、人工校准集、冻结盲测集、全链路 Trace Grader、多轮用户模拟、正式 RAG 评测、线上 A/B 与真实商家业务指标。
- 当前原则：模型可辅助规划和基于证据的表达；商品事实、兼容性规则、订单授权、政策适用和高风险退出仍由数据、工具与 Harness 决定。
