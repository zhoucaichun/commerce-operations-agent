# B2B 多租户演示实施计划

## 目标

将既有单租户 3C Agent 扩展为可演示、可测试的 B2B 产品闭环。付费客户为跨境 3C 独立站商家；其消费者使用 Widget，其客服、运营和管理员使用 Merchant Console。

## 第一阶段：合成多租户闭环

1. 建立两家演示商家及彼此独立的合成商品、订单、会话、工单和指标。
2. 增加 Widget 配置和聊天 API，所有调用均显式传入 merchant_id。
3. 增加 Merchant Console 概览、模拟工单状态处理、运营指标和 Widget 安装片段 API。
4. 新建 `/widget` 与 `/console` 页面；角色选择器只用于演示，页面须清楚说明它不是正式认证。
5. 用 API 和前端静态测试证明租户隔离、未知租户拦截、消费者与商家角色分离。

## 后续阶段（未实现）

| 阶段 | 前置条件 | 内容 |
|---|---|---|
| 生产多租户数据层 | 安全设计评审 | tenant_id 迁移、RLS、备份恢复、审计留存 |
| 商家接入 | 合同、数据处理协议、最小权限审批 | Shopify/OMS/ERP/物流适配器、只读沙箱与字段映射 |
| 正式身份 | 安全审批与 IdP 配置 | OIDC、组织/成员、RBAC、会话撤销 |
| 生产运营 | 演示验收通过 | 域名、TLS、监控、告警、计费和支持流程 |

## 不可越过的安全边界

首阶段没有真实商家数据库、真实用户身份或真实订单；不会扣库存、退款、取消订单、修改地址。唯一允许写入的是带幂等键的模拟工单及其模拟状态更新。
