# ShopPilot 3C RAG 实现说明

更新：2026-10-06。原 Dify 工作流已有 RAG；本项目迁移并完善为代码内可测试、可引用的链路。“没有生产 RAG”只能表示尚无真实商家生产接入，不能解释成原项目没有 RAG。

## 知识与事实源

当前目录含 278 条合成商品、37 条合成政策，以及合成 FAQ/商品说明。Dify 审查迁移数据与合成扩展目录构成知识来源；公开参考记录有来源与时间标签，不是实时价格/库存。政策、FAQ、商品说明转换为带 `document_id / source / version / region / topic / effective_from / valid_until` 的文档。

SKU、价格、库存、订单和兼容性仍由结构化工具/规则提供。RAG 补充知识解释，不替代订单身份校验和结构化预算筛选；全部运行数据均属演示，未连接真实商家系统。

## 实际步骤

1. 将商品说明、政策和 FAQ 转为版本化知识文档。
2. 按 560 字符分块，80 字符重叠，保留词边界与原文元数据。
3. 配置向量服务时批量生成语义向量；查询与文档使用相同服务/模型，并校验非空、有限数值和维度。默认每批八条，上限十条。
4. 构建进程内向量索引与 BM25 词法索引；首次检索惰性建索引。
5. 检索前按 kind、地区、主题及生效/失效日期硬过滤。
6. 融合 BM25、余弦相似度、标题和地区分数排序，选取引用片段。
7. `policy_search / knowledge_search` 返回证据与 `document_id / chunk_id / source / version`；Graph 将其作为下一次规划和表达的上下文。
8. 没有适用政策证据时接管；已有结构化目录证据但没有补充知识时明确限制，不编造知识内容。

## 切分为什么这样做

常见方案包括固定字符/Token、递归分隔、按句子/段落、标题章节、语义切分、父子文档切分。本项目使用固定字符窗口和重叠，因为当前多数说明和政策短、结构相近，实现简单、离线可复现；重叠降低边界信息丢失。这不是 Token 切分，也不是语义/递归切分。560/80 是初始工程参数，不是已被实验证明最优；长手册、表格和跨章节规则需要比较章节/父子切分，按召回、引用正确性和成本决定。

## 向量化与模型为什么这样选

词袋/TF-IDF 与 BM25偏字词匹配；特征哈希是离线基线，不是真正语义理解；稠密语义 Embedding 适合同义改写；混合检索结合两者。中文政策与英文 SKU 混合，因此本项目选择 BM25 + 语义向量，而不只用稠密检索。

当前用户候选为阿里云百炼 `text-embedding-v4`，与聊天平台分开配置。选择理由是已有账户、可用兼容接口和中英文本需求，不是未经对照的“业内最优”。可对照 BGE、E5、其他 Qwen/商用 Embedding，但型号性能、价格和授权必须在实际选型时核验。同一测试集比较质量、延迟、成本、长文本与中英混合表现后才定最终模型。

缓存按服务地址、模型 ID、文本内容哈希隔离，SQLite 保存可选向量缓存；更换模型或同 ID 后端版本变化须重建/清缓存。向量索引本身仍在内存，不是 pgvector 或 ANN 服务。当前是加权分数融合，不是神经 Reranker；是否增加 Reranker 要用消融实验判断。

## 离线与联网必须分开

未配置向量模型或显式离线评测使用 `HashingEmbedder`，检索模式标记 `local_hashing_demo`。语义接口失败标记 `lexical_degraded`；这不算语义成功。语义 API 的单条连接探测已有记录，但全量建索引+聊天端到端联网验收尚未完成。

`python src/eval/run_rag_eval.py` 默认无网络。11 条合成专项样本中十条可回答、一条空证据；当前离线 Recall@4=1.00、MRR@4=0.875、过滤正确率=1.00、空证据正确率=1.00。Recall/MRR 只统计可回答样本，空证据另算；旧 0.886 口径已废弃。小型开发集结果不能证明盲测、真实商家或语义模型效果。

联网专项用 `python src/eval/run_rag_eval.py --live --report reports/model/rag-live.json`；端到端用 `python src/eval/run_agent_eval.py --live --report reports/model/agent-live.json`。需记录模型/数据版本、回退、耗时，并补人工校准的忠实性、引用与相关性评测。

对应代码：`rag.py / embeddings.py / tools.py / graph.py`（均在 `src/backend/commerce_agent/`）。统一配置见 [模型配置](模型选型与统一配置.md)，任务验收见 [升级验收](升级验收与待审批事项.md)。
