# 升级验收与待审批事项

更新：2026-10-06。此文记录实现和证据，不宣称生产上线或真实商家效果；不沿用原 Dify 简历数字。

## 已实现

- 模型接口与受控规划/表达；统一后端 `.env`，不复制秘密到前端或镜像。
- LangGraph 同请求工具观察→重规划，最多六次工具调用，重复动作接管。
- 工具输入/输出校验、只读超时和一次瞬时错误重试，模拟工单幂等。
- 多轮槽位补充/覆盖、场景切换、订单变更清除身份、记忆删除和主体/租户范围隔离。
- 语义向量批量适配器、可选 SQLite 缓存、BM25 融合、元数据/日期过滤、引用证据；离线明确使用哈希基线。
- API 与 Widget 的鉴权、商家令牌绑定、限流和幂等；前端展示执行记录、模型参与与引用。
- 版本化开发任务集、离线/联网分开、联网聊天/向量失败前置终止。

## 唯一验证入口

仓库根目录执行 `python src/eval/run_project_checks.py`，默认完全离线，不调用模型服务。

同一入口加 `--live --limit 3` 是联网小批检查，会使用额度，先检查聊天和向量接口；不是完整发布验收。完整开发集用 `python src/eval/run_agent_eval.py --live --report reports/model/agent-live.json`。

需要审批的项目遵循 [安全审批清单](../operations/SECURITY_APPROVAL_CHECKLIST.md)；没有批准前仍是合成 MVP。
