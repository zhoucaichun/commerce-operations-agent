# 模型选型与统一配置

更新日期：2026-10-06。本文是统一说明；实际填写的模型配置只有 `src/backend/.env`，模板为同目录 `.env.example`。不再维护后端 `.env.local`。旧 Dify 密钥不是新 Agent 的模型密钥。

## 1. 选型依据与结论

本轮依据用户的平台截图和仓库调用代码做候选分工。官方网页检索失败，直接读取模型卡也未成功；因此不能核验截图中全部精确版本、量化效果、上下文长度、工具能力或结构化输出支持。以下是待实测的候选，不是官方性能排名或“最优模型”结论。截图报价也只是该网关当时的价格，不是官方定价或长期承诺。

| 截图模型 | 建议分工 | 理由与边界 |
|---|---|---|
| `Qwen3.6-35B-A3B` | 首个主聊天候选：意图、槽位、规划与证据回答 | 先以一个文本候选建立基线，减少多模型在线路由变量；并未证明它优于 DeepSeek。截图输入/输出均为 ¥3.6770/百万 Token。 |
| `DeepSeek-V4-Flash-0731-W8A8` | 主模型成本/质量对照；后续可试作独立评测裁判 | 截图输入/输出均为 ¥2.0430/百万 Token，相同 Token 数下约低 44.4%。实际请求成本还取决于输出长度与调用次数；Flash 名称不证明低延迟，精确后缀与量化效果未核验。裁判需要人工校准。 |
| `Qwen3-VL-30B-A3B-Instruct` | 后续图片理解候选 | 按 VL 名称暂定视觉候选，不代表图片链路已接入；文本客服先不增加视觉调用变量。截图报价 ¥3.6770/百万 Token，图片计费方式需另核对。 |
| `doubao-seed-2.0-code-previ...` | 暂不用于客服主模型，可另用于开发辅助 | 按 code 名称暂定代码候选；截图 ID 被截断。客服目标是导购、政策和订单，不因报价 ¥1.8390/百万 Token 就选代码模型。 |

建议先试 Qwen 文本候选，再用 DeepSeek 跑同一任务对照。如果 DeepSeek 达到同样质量、安全且成本/延迟更合适，就改用它；不坚持品牌。完整模型 ID 用平台复制按钮获取，不能照抄省略号。

## 2. 所有模型使用位置

| 环节 | 配置及实际状态 | 必要性 |
|---|---|---|
| 意图理解、槽位提取、结构化规划 | `COMMERCE_LLM_*`；已有真实聊天 Adapter 和同请求重规划循环；全量联网验收待完成 | 完整模型驱动 Agent 必需 |
| 基于证据的答复 | 当前与 Planner 共用同一个 Adapter | 必需；填配置不代表忠实性已验收 |
| RAG 文档/查询向量 | `COMMERCE_EMBEDDING_*`；批量接口/缓存已实现，单条连接探测已通过；全量索引与端到端验收待完成 | 语义 RAG 必需 |
| 语义质量评测裁判 | 独立 Judge Adapter 尚未接入，模板只留备忘 | 后续评测角色，不掌握线上动作权限 |
| 图片理解 | 当前只处理合成附件元数据，无真实图片模型调用 | 文本闭环非必需 |
| 语音识别/合成 | 无真实 ASR/TTS Adapter，截图没有对应服务 | 暂不要求 |
| 神经重排 Reranker | 当前是检索分数融合，不是专用模型重排 | 暂不启用，先做召回/重排对照实验 |
| 商品、兼容规则、订单归属、模拟工单 | 受控工具，不需模型配置 | 模型不能替代事实、权限与事务规则 |

### 向量模型缺口

2026-10-06 更新：已在用户百炼北京区控制台确认 `text-embedding-v4`，并创建仅允许该模型调用的项目专用 API Key。控制台标准价格为 0.5 元/百万输入 Token，免费额度显示为 0；已有单条向量接口探测记录；不代表全量语义索引和任务验收通过。聊天仍使用用户的另一平台，百炼地址与密钥必须单独填入同一个 `.env` 的 `COMMERCE_EMBEDDING_*` 区域。下述内容保留为其他平台候选的选择方法。

截图四个模型不能据此确认为专用向量模型。请在平台搜索 Embedding/向量模型，确认可用完整 ID、向量接口、中文/英文支持、批量限制与价格。可以询问是否提供 Qwen3-Embedding 系列或 BGE-M3 等候选，但不表示账号已拥有或本轮核验过。

先用能满足中文/英文、型号/SKU、地区条款检索的小成本候选建立基线，再用同一金标集比较召回、延迟和费用，决定是否值得换更大模型。不用聊天模型伪造向量，不把 Hashing Embedding 称为语义模型。

文档与查询必须使用同一向量模型/维度；更换模型须重建索引。当前缓存按服务地址、模型 ID 和文本内容隔离。平台在相同 ID 下更换实际模型时，应清除旧索引缓存。

## 3. 一个文件填写完

在仓库根目录复制模板；若文件已存在，不要覆盖，直接编辑：

```powershell
Copy-Item src/backend/.env.example src/backend/.env
```

聊天必填三项：`COMMERCE_LLM_BASE_URL`、`COMMERCE_LLM_API_KEY`、`COMMERCE_LLM_MODEL`。模板暂定 Qwen 候选，ID 以平台复制的完整值为准。Base URL 为服务根地址或以 `/v1` 结尾，不填完整 `/chat/completions`。

语义 RAG 另填 `COMMERCE_EMBEDDING_MODEL`。向量服务与聊天共用地址/密钥时，`COMMERCE_EMBEDDING_BASE_URL`、`COMMERCE_EMBEDDING_API_KEY` 留空即可；不同服务才分别填写。不支持向量接口时需要另选可用服务。

首试 `COMMERCE_LLM_RESPONSE_MODE=json_object`，仍需网关实际兼容；`json_schema` 只有网关支持且当前 Schema 验证兼容后再启用。本地校验始终保留。`COMMERCE_LLM_PROVIDER` 只是记录标签，不会替你选择模型或服务。

`COMMERCE_EMBEDDING_CACHE` 留空不落盘；需要持久化时填本仓库 `reports/` 下路径。相对路径以启动目录为准。未填向量模型时是离线哈希模式；语义接口失败时标记词法降级，不能将降级结果算作语义模型成功。

使用英文等号，不用中文弯引号，不在值尾部添加注释。环境变量优先于文件，建议新窗口启动，避免旧 `$env:COMMERCE_*` 覆盖。不要发密钥、截图、完整环境变量或完整 Compose 配置输出；它们可能泄露秘密。

裁判、图片、语音和重排当前未接入，模板仅留中文备忘，不设置虚假的“生效字段”。这些角色接入时仍应统一到本文件，无需再建一套模型密钥。

## 4. 各入口读取同一文件

### 本地 API

```powershell
python -m uvicorn main:app --app-dir src/backend --host 127.0.0.1 --port 8000
```

`main.py` 显式加载后端 `.env`。不要用 `commerce_agent.api:app` 绕过加载入口。后端实际聊天请求可以调用模型，不需要 `--live`；修改文件后重启后端。

### 模型试验

```powershell
python src/eval/run_dify_model_eval.py --live --limit 3 --report reports/model/connection-trial.json
```

只有 `--live` 加载文件并调用模型；默认不加载、不发送题目。此 runner 是历史 Dify 迁移对照，不等于新版完整 Agent 评测，也没有独立语义 Judge。先看模型实际参与、错误与回退诊断，不把规则兜底当成模型成功。

### Docker Compose

```powershell
docker compose --env-file src/backend/.env -p commerce-agent -f src/infra/docker-compose.yml up --build -d
```

Compose 显式将同一文件的聊天/向量配置传给后端；容器缓存固定为 `/data/embedding-cache.sqlite3`，保存在已有数据卷。不把文件复制进镜像。配置不等于容器全栈和真实模型验收；执行证据见升级验收文档。

### 前端

Next.js 保留自己的后端地址配置，这是服务连接而非模型配置。模型密钥不放浏览器或 BFF，模型调用仅在后端。历史 Dify 页面仍有独立配置，但不属于新版店铺 Agent 链路。

## 5. 最终选型如何验收

相同代码、Prompt、数据、工具、任务集下对照 Qwen 和 DeepSeek；分别记录精确模型 ID。先做 3 条连接检查，再覆盖推荐、兼容、政策、订单、多轮补充、约束修改、无证据、越权场景。

比较结构化输出有效率、实际工具/参数正确性、任务完成、事实/引用一致性、失败回退、请求耗时和供应商返回 Token；质量安全达到要求后再比成本。不要只看模型名、参数量、报价或回答文风。

没有密钥时只能做本地接口契约与加载测试，不能宣称真实模型通过。当前受控 Agent、记忆、工具契约和语义适配器已实现；实际质量仍以全量联网报告为准。验收入口见 [升级验收](升级验收与待审批事项.md)。旧 Dify 简历数字不用于新 Agent。

## 当前推荐验证入口

先执行 `python src/eval/run_project_checks.py`（不调用模型）。联网小批执行 `python src/eval/run_project_checks.py --live --limit 3`，聊天和向量探测失败会停止。完整集用 `python src/eval/run_agent_eval.py --live --report reports/model/agent-live.json`。语义批量默认八条，可用 `COMMERCE_EMBEDDING_BATCH_SIZE` 调整（上限十条）；模型服务不同须分别填地址/密钥，但都在同一个后端 `.env`。
